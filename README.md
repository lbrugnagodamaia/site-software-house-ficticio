Dev Mind | Software House Fictícia



Landing page de uma software house fictícia, desenvolvida durante meus estudos de Front-end.



\-> Objetivo



O projeto foi desenvolvido para praticar a criação de uma página web completa, explorando estruturação HTML, estilização com CSS e organização de layouts.



\-> Tecnologias



\- HTML5

\- CSS3



\-> Conceitos praticados



\- Flexbox

\- CSS Grid

\- Responsividade

\- Variáveis CSS

\- Media Queries

\- Formulários

\- Organização de arquivos CSS



\-> Sobre o projeto



Este é um projeto fictício desenvolvido como parte dos meus estudos em desenvolvimento Front-end.
